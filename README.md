# stm\_adc\_signal\_acquisition\_fft

STM32信号采集 + Python FFT频谱分析项目



## 项目简介

本项目实现STM32采集模拟信号，通过串口上传至电脑，使用Python绘制时域波形并做FFT频谱分析。

是嵌入式、信号处理综合练习项目。



## 技术栈

* STM32 + Keil MDK
* CubeMX配置外设（GPIO / USART / ADC / TIM）
* Python：pyserial、numpy、matplotlib



## 目录说明

* firmware：STM32 Keil工程
* python\_host：Python上位机代码
* test\_data：截图、CSV实验数据
* doc：接线图、说明文档
